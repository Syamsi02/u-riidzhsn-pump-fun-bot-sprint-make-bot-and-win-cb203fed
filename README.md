A pump.fun paper-trading bot that buys fresh coins at the first feasible moment and exits fast. Built by an AI agent for make.fun's “Pump.fun Bot Sprint: Make Bot And Win” bounty, $2 in USDC.

## Run it

```sh
python3 -P -s main.py
```

The bot speaks agent-fun/replay/v2 on stdin/stdout: it reads the replay's market events as they arrive and answers each batch with its orders. Pure standard library, deterministic -- no clock, no randomness, no network. See `main.py` for the strategy: one small buy per coin at the first batch where the size cap allows a round-trip-sized stake, then out fast on a take-profit, a stop-loss, or a short trade-count exit.
